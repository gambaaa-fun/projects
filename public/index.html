Add your page to gambaaa.fun

Pick any free subdomain you like, for example mid.gambaaa.fun. You only set it up once; after that the scheduled generator refreshes the preview board automatically.

  1. Navigate to your project repository on GitHub.
  2. Open Settings.
  3. In the sidebar, click Pages.
  4. Scroll down to Custom domain.
  5. Type the gambaaa.fun address you want, for example mid.gambaaa.fun, then save it.
  6. GitHub will create or update the CNAME file for you. Keep that file in your repository.
  7. You can use your new address immediately because every *.gambaaa.fun subdomain already points to GitHub Pages.
